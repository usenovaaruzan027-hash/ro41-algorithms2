# Руководство по рекурсии в программировании

## 1. Что такое рекурсия?
**Рекурсия** — это процесс, при котором функция вызывает саму себя для решения подзадачи меньшего размера. 

Каждая рекурсивная функция должна состоять из двух обязательных частей:
1. **Базовый случай (условие выхода)** — условие, при котором функция прекращает вызывать саму себя и возвращает конкретное значение. Без него программа зависнет и вызовет ошибку переполнения памяти.
2. **Шаг рекурсии** — вызов функции с измененными (обычно уменьшенными) аргументами, приближающий задачу к базовому случаю.

---

## 2. Как работает стек вызовов (Call Stack)?
Когда вызывается рекурсивная функция, каждый новый вызов помещается в **стек вызовов** (call stack). 
* При движении **вниз** по стеку аргументы передаются, а вызовы накапливаются, пока не сработает базовый случай.
* При движении **вверх** значения начинают возвращаться и объединяться (вычисляться) от базового случая к начальному вызову.

Если базовый случай задан неверно или недостижим, стек переполняется, что приводит к ошибке **`StackOverflowError`**.

---

## 3. Пример на C#: Вычисление факториала

Ниже приведен классический пример рекурсивной функции для расчета факториала числа $n$ ($n!$):

```csharp
static int Factorial(int n)
{
    // 1. Базовый случай
    if (n <= 1)
    {
        return 1;
    }
    
    // 2. Шаг рекурсии
    return n * Factorial(n - 1);
}
