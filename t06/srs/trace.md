### 1. Трассировка циклического сдвига влево на одну позицию

Исходный массив: $a = \{4, 1, 7, 3, 9\}$, размер $n = 5$.
Алгоритм сохраняет первый элемент в буфере (`int buf = a[0];`), сдвигает элементы влево, а затем записывает буфер в конец (`a[n - 1] = buf;`).

| Шаг | Индекс $i$ | Действие / Описание | Состояние массива после шага |
| :---: | :---: | :--- | :--- |
| **Старт** | — | `buf = a[0]` (buf = 4) | `{4, 1, 7, 3, 9}` |
| **1** | $1$ | `a[0] = a[1]` | `{1, 1, 7, 3, 9}` |
| **2** | $2$ | `a[1] = a[2]` | `{1, 7, 7, 3, 9}` |
| **3** | $3$ | `a[2] = a[3]` | `{1, 7, 3, 3, 9}` |
| **4** | $4$ | `a[3] = a[4]` | `{1, 7, 3, 9, 9}` |
| **Финал** | — | `a[4] = buf` (запись из буфера) | `{1, 7, 3, 9, 4}` |

### 2. Трассировка разворота массива на месте

Исходный массив: $a = \{4, 1, 7, 3, 9\}$, $n = 5$.
Цикл выполняет обмен элементов `a[i]` и `a[n - 1 - i]` для $i$ от $0$ до $\lfloor n / 2 \rfloor - 1$.

* **Трассировка обменов:**
  * При $i = 0$: обмен `a[0]` (4) и `a[4]` (9) $\rightarrow$ массив принимает вид: **`{9, 1, 7, 3, 4}`**
  * При $i = 1$: обмен `a[1]` (1) и `a[3]` (3) $\rightarrow$ массив принимает вид: **`{9, 3, 7, 1, 4}`**
  * При $i = 2$: цикл завершается, так как $i$ достигает значения $\lfloor 5 / 2 \rfloor = 2$. Средний элемент (`7`) остается на своем месте.

* **Ответы на вопросы:**
  * **Сколько выполнено обменов?** Выполнено **2** обмена (для $i = 0$ и $i = 1$).
  * **Почему цикл выполняется только до $n / 2$?** Если выполнять цикл до конца массива ($n$), то элементы успеют поменяться местами дважды, и массив вернется в исходное состояние. Цикл до середины ($n / 2$) позволяет корректно зеркально развернуть все элементы ровно один раз.

### 3. Анализ алгоритма поиска минимума

* **Проблема с начальным значением `min = 0`:**
  Если инициализировать переменную поиска минимума индексом `int min = 0`, алгоритм будет предполагать, что минимальный элемент находится на нулевой позиции. 
  * Если все числа в массиве **положительные** (например, `{4, 1, 7, 3, 9}`), алгоритм отработает корректно, так как сравнивает значения с `a[min]`.
  * Однако, если первый элемент массива окажется **строго больше** минимального значения среди остальных элементов (или если массив содержит отрицательные числа, а первый элемент равен нулю), такой подход может привести к логической ошибке, если индекс `min` жестко завязан на значение, а не на поиск. 
  * *Примечание:* Чаще под `min = 0` в литературе подразумевают начальный **индекс** минимального элемента (`int minIndex = 0;`), либо начальное значение самого элемента `int min = a[0];`. Если же алгоритм ищет минимум по индексу, присвоение `min = 0` корректно при условии, что сравниваются значения `a[i] < a[min]`.
  * **Исправление:** Чтобы алгоритм поиска минимального элемента работал корректно для любых данных, в качестве начального значения следует брать **первый элемент массива** (`int min = a[0];`) или **нулевой индекс** с обязательной проверкой значений (`int minIndex = 0;`).
